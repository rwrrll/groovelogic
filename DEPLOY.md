# Deploying the Groove Logic site

Static files for GitHub Pages. No build step.

- index.html   the landing page (fonts load from Google Fonts)
- favicon.svg  site icon
- CNAME        custom domain (www.groovelogic.co.uk). Keep this existing value; groovelogic.co.uk redirects here.

GitHub Pages publishes the root of the `master` branch in `rwrrll/groovelogic`.

To deploy: update the static files, commit, and push to `master`. Pages republishes automatically; check the Pages build and https://www.groovelogic.co.uk/ after pushing.
